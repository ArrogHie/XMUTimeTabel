## 目标

针对厦门大学专属版修 5 项:手动登录抓取失败(桌面 UA)、同课多教室合并、网格视图外观自定义、WeekGrid 小组件自定义+全局开关、新 logo 接入桌面图标。

## 1. 修复手动登录抓取失败(移动端 UA 问题)

**根因**:`JwWebViewLoginScreen` 的 `XmuJwWebView` 未设 UA,Android 默认手机 UA 使厦大门户/统一身份认证渲染**移动版**,与 `schedule/fetch_xmu_schedule.py` 验证的**桌面版**接口时序(`jw.xmu.edu.cn/gsapp/wdkbapp/*`,页面 UA=Windows Chrome)不符 → 登录后抓取失败。

**改动**:
- `JwWebViewLoginScreen.kt`:WebView `settings.userAgentString = <桌面 Chrome UA>`(与 `XmuAutoLoginClient` 同一 UA 串,提到 `XmuJw.DESKTOP_UA` 常量共用)。
- 保留抓取 JS 的 `jw.xmu.edu.cn` 域名守卫;错误文案已明确提示"停留在教务门户"。
- 附带:`XmuJw.kt` 增加 `DESKTOP_UA` 常量,自动登录客户端复用。
- 验证:编译 + 说明(端到端需真机账号)。解析/落库链路已被既有单测覆盖。

## 2. 同课同时间多教室合并(消除网格重叠)

**根因**:`wdkcb/queryXspkjg.do` 把同一门课(同 courseCode、星期、起止节次、周次位图)因多个教室拆成多行(样例:UNIX 课双周 1-4 节 B311/B308 两行)→ 每行各渲染一条 → 网格同格重叠。

**改动(`JwXmuParser.kt`)**:
- `generateCourseList` 在拆周次前,按原始行 `(courseCode 缺失则 KCMC、XQ、KSJCDM、JSJCDM、ZCBH)` 分组合并:
  - 教室:`JASMC` 非空去重,`" / "` 连接(空教室行并入其它,不产生空卡);
  - 教师:`JSXM` 按逗号拆、去重后再 `", "` 连接;
  - 其余字段取组内首行;合并后单行再走 weekRuns 拆周次 → `JwCourse`。
- key 严格限定同 code+同星期+同起止节+同周次位图 → 不会误合并不该合的课(不同时间/单双周/不同课程不合并)。
- **测试**:改 `JwXmuParserTest` 的"多条排课行各自产出课程"用例为"同课同时间多教室合并成 1 条、room 含两教室";另加教师去重、不同课程不误合并两条用例。

## 3. 网格视图(课表-网格)外观自定义

**范围**:`CardsGridView`/`CourseOverlayCard`/冲突卡;不动周视图。

**(a) 卡内容三项自由开关**(替代现有 room/teacher/none 三选一):
- `AppPrefs` 新键:`KEY_GRID_SHOW_ROOM`(默认 true)、`KEY_GRID_SHOW_TEACHER`(默认 false)、`KEY_GRID_SHOW_TIME`(默认 false);首次读取时按旧 `grid_sub_info` 迁移一次(room/teacher/none → 对应开关组)。
- `CourseOverlayCard` 与冲突卡副信息区改为按开关拼行(最多 2~3 行小字):时间行取 `timeSlots[startNode]~timeSlots[endNode]` 的 HH:mm(由 `CardsGridView` 传入 node→起止 映射,卡片无需存时间);教室/老师组合行。
- `CardsGridView` 订阅 changeBus 新键,改设置同帧生效。

**(b) 行列间距独立滑杆**:
- `AppPrefs`:`KEY_GRID_GAP_H`(默认 4dp)、`KEY_GRID_GAP_W`(默认 5dp),范围 0~16dp、步进 0.5;渲染层 `gapH/gapW`(含列宽/行高/表头/时间行计算)改用新值并乘 scale;changeBus 订阅。

**(c) 圆角**:已有 `grid_corner_ratio` 全局滑杆已作用于课程卡/时间卡/表头(含冲突卡补齐:冲突卡圆角从固定 `shapes.medium` 改为同乘 cornerRatio/scale)。无需新键。

**(d) 设置 UI**(`GeneralSettingsScreen.kt`):
- 原"网格卡片副信息"三选一卡替换为三个独立开关行(地点/老师/时间)+说明;
- "主页显示设置"折叠卡内新增 行间距/列间距 两根滑杆(照抄现有 slider 模式);
- 文案:6 语言 `strings.xml` 新增对应 key。

## 4. 小组件自定义(仅网格 WeekGrid + 全局开关)

用户取向:仅 WeekGrid 做完整几何自定义;周六日/时间作全局开关应用到各适用形态;Today/TwoDay/WeekList/WeekView 几何不动。

**(a) `AppPrefs` 新键**:
- `KEY_WIDGET_HIDE_WEEKEND`(bool,默认 false)——全局:WeekList/WeekView/WeekGrid 渲染与滚动高度计算前从可见天中剔除 6/7(与主课表 `visible_days` 相互独立);
- `KEY_WIDGET_SHOW_TIME`(bool,默认 true)——全局:WeekGrid 时间列显隐、Today/TwoDay 时间 meta 行显隐(默认跟随原行为);
- `KEY_WIDGET_GRID_CORNER`(float dp,默认 10,0~24)——WeekGrid 课程卡圆角;
- `KEY_WIDGET_GRID_GAP_H`/`KEY_WIDGET_GRID_GAP_W`(float dp,默认 1.5/2.5,0~8)——WeekGrid 行/列间距;
- `KEY_WIDGET_GRID_FONT_SCALE`(float,默认 1.0,0.8~1.3)——WeekGrid 内容字号密度(等效"观感放大",因 widget 总尺寸由桌面系统决定、卡片宽高跟随 cell,无法真正自定义长宽——在 UI 副标题说明)。

**(b) 渲染**:
- `WeekGridWidgetProvider.kt` `renderBitmap`/`loadWeekData`:时间列宽按 `widget_show_time` 设为 0 或默认;`gapH/gapW/圆角/字号` 改用新键;周末剔除。
- `WidgetBitmapRenderers.kt`:`renderWeekListRegular`/`renderWeekViewRegular`/`renderTodayRegular`/`renderTwoDayRegular` 开头按全局键处理(剔除周末列/隐藏时间 meta);WeekList/WeekView 各自的 `xxxContentHeightDp` 镜像函数同步同一过滤(保持滚动高度正确)。
- 这些键只新增读取、不改 REGULAR 原默认渲染数值(默认与现状逐像素一致)。

**(c) 设置 UI**(`GeneralSettingsScreen.kt` 分组②"小组件"):新增
- 全局开关行:显示时间、隐藏周六日;
- "网格小组件外观"折叠卡:课程卡圆角/行间距/列间距/字号密度 4 根滑杆。
- 每处修改后调 `refreshWidgets()`;文案 6 语言新增。

## 5. 新 logo 接入桌面图标

`assets/logo.png`(用户已更新的图)作为桌面图标源:
- 用 PowerShell + System.Drawing 读取尺寸,等比缩放到 5 密度生成 `mipmap-{m,h,xh,xxh,xxxh}dpi/ic_launcher.png` 与 `ic_launcher_round.png`(legacy 图标,桌面会套圆角遮罩);
- 自适应图标(`mipmap-anydpi-v26/ic_launcher[_round].xml`):foreground 引用新生成的高清 PNG 并居中缩到安全区(画布 66%),background 沿用现 `ic_launcher_background`;若 logo 为方形不透明,自适应下会被系统遮罩裁角——优先采用"background 用现底色 + foreground 用 logo"的常规组合,避免裁掉内容;
- 顺带:`AboutScreen`/分享等可见品牌位若引用旧 `ic_launcher` 或 `logo` 会自然跟随;README 顶图继续用 `assets/logo.png`(已在仓库)。
